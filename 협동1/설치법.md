### Docker설치가 안되어있다면
첨부파일 `InstallFile.zip`을 압축 해제 후

`01_Install_docker.sh`가 있는 곳으로 경로 이동 후

```bash
bash 01_Install_docker.sh
```
를 실행.


### 워크스페이스 및 폴더 생성

```bash
mkdir -p ~/ws_cobot_pjt/ws_dsr
cd ~/ws_cobot_pjt/ws_dsr
```

### 다운로드
```bash
git clone https://github.com/ahnisinc/cobot_rg2.git
##폴더이름을 바꿉니다.
mv cobot_rg2 src
```

### 에뮬레이터 설치

```bash
cd ~/ws_cobot_pjt/ws_dsr/src/doosan-robot2
./install_emulator.sh
## 또는
source ./install_emulator.sh
```

### 의존성 설치

```bash
cd ~/ws_cobot_pjt/ws_dsr
rosdep install -r --from-paths src --ignore-src --rosdistro $ROS_DISTRO -y
```

### 빌드
```bash
cd ~/ws_cobot_pjt/ws_dsr
colcon build
source install/setup.bash
```

### bashrc 수정

```bash
sudo nano ~/.bashrc
```

로 들어가서 맨 아래 아래 명령어를 추가

```bash
export PYTHONPATH=$PYTHONPATH:~/ws_cobot_pjt/ws_dsr/install/dsr_common2/lib/dsr_common2/imp 
```


### 실행 준비

```bash
source ~/ws_cobot_pjt/ws_dsr/install/setup.bash
```

### 실행

```bash
ros2 launch m0609_rg2_bringup bringup.launch.py
## 또는 아래 명령어(같은 명령어임.)
ros2 launch m0609_rg2_bringup bringup.launch.py mode:=virtual host:=127.0.0.1 model:=m0609
```

아래 명령어는 실제 로봇과 연결해서 실행하는 명령어
```bash
ros2 launch m0609_rg2_bringup bringup.launch.py mode:=real host:=192.168.1.100 model:=m0609
```
